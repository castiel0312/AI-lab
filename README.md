# Artificial Intelligence Lab – Semester 5

This repository contains Python programs implemented as part of the **Artificial Intelligence Laboratory (Semester 5)** coursework.

## Programs Included

| Program | Description |
|---|---|
| `A*` | Implementation of the A* search algorithm |
| `A*2` | Another implementation of the A* search algorithm |
| `Hill Climbing` | Implementation of the Hill Climbing search algorithm |
| `IDS` | Implementation of Iterative Deepening Search |
| `Simulated Annealing` | Implementation of the Simulated Annealing optimization algorithm |
| `tictactoe` | Tic-Tac-Toe game demonstrating AI concepts |

## Technologies Used

- **Language:** Python
- **Concepts:** Search Algorithms, Heuristic Search, Optimization, and Game Playing

## Getting Started

### Prerequisites

- Python 3 installed on your system
- A code editor or terminal to run the programs

### Running the Programs

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the repository directory:

   ```bash
   cd <repository-folder>
   ```

3. Run the desired program using Python:

   ```bash
   python3 "Hill Climbing"
   ```

   Replace `Hill Climbing` with the filename of the program you want to execute. Add the appropriate file extension if your files have one.
